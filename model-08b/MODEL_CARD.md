# SymbolicLight V1 0.8B Model Card

SymbolicLight V1 0.8B is a base pre-trained spike-gated dual-path language
model. It has not been post-trained as an instruction-following assistant.

- Parameters: 873,668,135
- Structural vocabulary size: 57,344
- Active tokenizer vocabulary: 55,296
- Context length represented by the released configuration: 512
- Weights: <https://huggingface.co/SymbolicLight-AGI/SymbolicLight-V1>

The release provides the model definition and a minimal inference example.
The private training pipeline, dataset recipe, preprocessing implementation,
and original launch commands are not included.

Generated text may be inaccurate, repetitive, biased, or unsafe. Users should
evaluate outputs for their application and must not treat the base checkpoint
as a reliable instruction-following system.
